# Holberton School - Analysis and Design

This repository and project were made in the context of learning at Holberton School. The project goal was to learn about software analysis, design, and modeling techniques including UML diagramming, relational database design, functional specifications, and API-first design principles.

## Repository Structure

- **API_first**: API-first design principles and RESTful API design
- **Modelisation_Relationnelle**: Relational database modeling and schema design
- **SpecFonct**: Functional specifications and requirements documentation
- **UML_Avance**: Advanced UML modeling including class diagrams, sequence diagrams, and use case diagrams
- **blueprint_stockmaster**: Project blueprints and architecture design
- **data**: Data models, schemas, and database definitions
- **docs**: Project documentation
- **scripts**: Utility and automation scripts
